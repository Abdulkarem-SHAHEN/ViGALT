\section{Methodology}
Fig.~\ref{fig:pipeline} shows the \sys generation pipeline, which currently targets two product families: clothing and furniture.

\begin{figure}[t]
\centering
\input{figures/pipeline_tikz}
\caption{\sys generation pipeline. Validators 5--7 run in parallel on the same atomic claims and act as generation-time safeguards; they are distinct from the post-hoc evaluation metrics of Section~\ref{sec:results}. The fuser also receives the candidate text and claims (dashed).}
\label{fig:pipeline}
\end{figure}

\begin{enumerate}
\setlength{\itemsep}{1pt}
\item \textit{Categorizer.} Assigns the product to clothing or furniture so that later prompts focus on category-appropriate attributes.
\item \textit{DOM extractor.} A deterministic script extracts product information from the page into structured JSON (e.g., color, material, sleeve type, neckline, and fit for clothing; analogous attributes for furniture). This JSON represents what the user can already learn from the page.
\item \textit{Generator.} The image and DOM JSON are passed to a VLM (\gen), instructed to describe visually meaningful details not already covered by the DOM.
\item \textit{Atomic claim separation.} The candidate is decomposed into independently checkable semantic claims, in the spirit of atomic-fact evaluation \cite{min2023}, so that validation operates on single facts rather than multi-fact sentences.
\item {\sloppy\textit{Redundancy validator} (claims + DOM). Labels each claim \texttt{NOVEL}, \texttt{UNAVOIDABLE\_REPETITION} (repetition needed to anchor a new visual relation, e.g., ``the hoodie'' in ``the hoodie has a small logo on the left chest''), or \texttt{AVOIDABLE\_REDUNDANCY}.\par}
\item \textit{Accuracy validator} (claims + image). Flags claims not supported by the image and may correct or delete them, reducing hallucination.
\item \textit{Completeness validator} (image + claims + DOM). Lists important visible details absent from both the candidate and the DOM.
\item \textit{Fuser.} A constrained writer that removes or corrects rejected content, incorporates validated missing details, and produces concise final alt text. It introduces no new facts of its own.
\end{enumerate}
